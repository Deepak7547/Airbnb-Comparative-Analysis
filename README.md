# Airbnb Market Analysis Dashboard

## Project Overview

This project focuses on analysing and comparing Airbnb listings across Chicago and New Orleans using Exploratory Data Analysis (EDA) and Power BI to identify pricing patterns, property distribution, neighbourhood trends, and business insights.

## Project Type

Exploratory Data Analysis (EDA), Comparative Analysis & Power BI Dashboard

## Contribution

Individual

## Tools & Technologies

* Python
* Pandas
* Google Colab
* Power BI

## Project Objectives

* Analyse Airbnb listings across Chicago and New Orleans.
* Compare property prices and listing distribution.
* Identify popular neighbourhoods and room types.
* Analyse customer reviews and host activities.
* Generate actionable business insights.
* Develop an interactive Power BI dashboard.

## Project Workflow

1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Data Preprocessing
4. Comparative Analysis
5. Power BI Dashboard Development
6. Business Insights & Findings

## Dashboard Sections

1. Overview of Airbnb
2. Property Analysis
3. Pricing Analysis
4. Host Analysis

## Key Insights

* Chicago has more Airbnb listings than New Orleans.
* Entire Home/Apt is the most common room type in both cities.
* Average property prices differ between the two cities.
* Property availability varies across neighbourhoods.
* Neighbourhood-level pricing shows different market trends.

## Conclusion

This project demonstrates hands-on experience in Python-based data analysis, comparative analysis, and Power BI dashboard development to transform Airbnb listing data into meaningful business insights.
